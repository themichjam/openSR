# Contributing

Thanks for contributing to `opensr`.

## Local development

```r
devtools::document()
devtools::test()
devtools::check()
pkgdown::build_site()
```

## Principles

- Keep workflows fully open-source.
- Treat `opensr` as orchestration + provenance infrastructure.
- Do not add proprietary dependencies to core workflows.
- Keep PRISMA-aware wording accurate (never overclaim compliance).
